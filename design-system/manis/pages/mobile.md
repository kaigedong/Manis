# Manis UI 2.0 — Mobile UX Specification (Android Jetpack Compose)

> 继承 [MASTER.md](../MASTER.md) 全部设计 Token，针对 Android 手机（360–430dp）与平板/折叠屏（≥600dp）制定单手人体工学、安全区与 Compose 规范。

---

## 1. 移动端外壳与空间释放（Mobile Shell）

- **全面 Edge-to-Edge 安全区**：所有顶部栏与底部导航严格响应 `WindowInsets.safeDrawing` / `navigationBarsPadding()`，永不与状态栏、挖孔或手势小白条冲突。
- **底部 5 页签导航栏（64dp + 底部手势安全区）**：
  - 严格对齐桌面端 5 大工作区：`节点`、`规则`、`活动`、`日志`、`设置`。
  - 统一 1.75px 线宽矢量图标 + 11.5sp 中文标签，选中项采用电钴蓝图标 + `accent.soft` 顶部胶囊指示器，触控热区 ≥ 48×48dp。
- **彻底移除旧版 140dp 底部固定连接栏**：
  - 旧版将 140dp 连接栏叠在 72dp 底栏上方，吃掉 212dp（近 28% 屏幕高度）！
  - 新版采用 **顶部 Hero 连接驾驶舱 + 滚动吸顶迷你条**：首屏状态与开关醒目直达；向上滚动查看长节点列表时，自动在顶部平滑浮现 52dp 吸顶迷你连接条（状态点 + 出口名 + 开关按钮），单手可视列表空间增加 **+90dp**！

## 2. 移动端五大页面精雕规范

### 2.1 节点（Nodes — 首页）
1. **顶部品牌轻栏（48dp）**：左侧 `26dp` Manis 标识 + `Manis` 标题；右侧一键 `浅色/深色` 圆形切换按钮（48dp 触控热区）。
2. **Hero 连接驾驶舱（Bento 卡片，`radius.card = 14dp`）**：
   - **上区**：左侧为大号触觉状态指示 + 当前状态标题（`已保护 · 规则分流` / `未连接`）+ 出口节点与延迟（`香港 HK-01 · 38 ms`）；右侧为 **高辨识度电源主开关按钮**（`已连接` 翠绿柔底+断开图标 / `开启代理` 电钴蓝实心胶囊，触控区 ≥ 48dp）。
   - **中区（仅连接时展示）**：轻量等宽会话统计条（`↓ 14.2 MB` · `↑ 3.1 MB` · `12 活动连接`）。
   - **下区**：整宽 **3 段路由模式滑块**（`直连` | `规则` | `全局`），每个段均分宽度、44dp 高度，在 320dp 极窄屏下依然舒展不裁字。
3. **策略组列表**：卡片展示组名、策略标签、当前出口胶囊与单组测速按钮，点按平滑展开成员列表。
4. **订阅与手动节点**：首组默认展开，头部展示源名称、节点数与配额进度条；每行节点最小高度 `56dp`，左侧地区码 + 节点名 + 协议，右侧等宽延迟 + 测速触控区。

### 2.2 分流规则（Rules）
- 顶部紧凑标题栏（`分流规则` + `3 组 · 18 条`）+ 右侧 `+ 新建组` 与 `应用`（仅在有待保存改动时高亮电钴蓝，并配暖珀未应用圆点）。
- 优先级管道卡片：保留 48dp 左侧即拖把手（避免长按延迟），新增 `01` / `02` 序号徽标与皇家紫目标策略胶囊；同时在组菜单中提供「上移/下移」按钮，满足 WCAG 2.2 拖拽单点替代要求。
- 规则编辑与规则组编辑从全屏硬弹窗升级为 **圆角底部抽屉（ModalBottomSheet, `20dp` 顶部圆角）**，顶部带拖拽指示条，底部固定提交栏适配键盘 `imePadding()`。

### 2.3 网络活动（Activity）
- 顶部搜索框 + 紧凑实时汇总条 + 刷新按钮。
- 连接卡片采用与桌面端 100% 同源的 **Route Truth Chain**：主机名 + 上下行流量居上，下方以紧凑流式胶囊呈现 `规则 → 策略组 → 出口节点`。点按任意连接直接拉起预填好域名/IP 的规则底部抽屉。

### 2.4 日志（Logs）
- 顶部搜索栏 + 横向滚动的 **级别筛选胶囊**（`全部`、`ERROR`、`WARN`、`INFO`、`DEBUG`）+ 复制按钮。
- 日志卡片采用等宽字体，时间 + 级别胶囊一行，日志正文清晰换行不截断。

### 2.5 设置（Settings）
- **居中极简顶栏（52dp）**：移除杂乱的顶部横向快捷跳转胶囊条，二级页面提供返回箭头 + 居中标题，并接入 Android 系统返回手势。
- **顶部状态 Hero 卡片**：大圆角（18dp）留白卡片，左侧 46dp 语义图标徽章 + 当前连接状态与出口/来源摘要，右侧轻量圆角胶囊主操作（`开启` / `断开` / `去添加`）；仅在有未应用配置时展示精简提示条。
- **分组内嵌白卡（Inset Grouped List）**：组标题与说明文案静置在卡片外部，浅色下卡片无重描边（纯白浮于暖雪花石膏底色），深色下辅以 0.5dp 极细轮廓线；行高 ≥ 56dp，统一 32dp 圆角品牌图标徽章 + 单行标题 + 右侧当前值摘要 + 轻量化右箭头，行间采用与文字左对齐的 0.5dp 内缩分割线。
- **渐进式披露**：`订阅与节点`、`路由与内核`、`应用更新` 采用二级钻取页面；`外观`、`节点域名解析`、`备份与恢复`、`关于 Manis` 采用轻量圆角底部抽屉（ModalBottomSheet），避免首页堆叠重型表单与诊断信息。

## 3. Jetpack Compose 专项落地约束
- 遵循 `ui-ux-pro-max` Jetpack Compose 准则：所有颜色经 `LocalManisColors` & `MaterialTheme.colorScheme` 注入，严禁在页面文件写死十六进制颜色；保持扁平布局避免多余 `Box/Column` 嵌套；所有可点击组件具备明确水波纹/状态层反馈（≤100ms）与 `contentDescription`。
- 平板/横屏（`≥ 600dp`）自动切换为左侧 NavigationRail + 主内容区，与桌面 Medium 态无缝衔接。
