# Manis UI 2.0 — Desktop UX Specification (Rust GPUI)

> 继承 [MASTER.md](../MASTER.md) 全部设计 Token，针对 macOS / Linux / Windows 桌面端（GPUI + gpui-component）制定空间布局、窗口体系与交互规范。

---

## 1. 自适应窗口框架（Adaptive Shell）

| 断点 | 窗口宽度 | 左侧导航 | 策略组网格 | 内容最大宽度 |
| --- | --- | --- | --- | --- |
| **Wide** | `≥ 1280px` | `232px` 展开侧栏（图标 + 标签 + 底部实时遥测卡） | 2 列 Bento 网格 | `1160px` 居中舒适阅读 |
| **Medium** | `900 – 1279px` | `68px` 精致图标轨（Hover Tooltip） | 2 列紧凑网格 | 自适应填充 |
| **Compact** | `640 – 899px` | `56px` 精简图标轨 | 1 列垂直卡片 | 自适应填充 |

- 最小主窗口尺寸保持 `640 × 560` 逻辑像素；所有窗口保持 `WindowBackgroundAppearance::Opaque`。

### 1.1 左侧导航轨结构（Wide 232px）
1. **品牌区（56px，适配 macOS 红绿灯安全区）**：`28px` 官方 `manis-mark.svg` + `Manis` 15px Semibold 字标 + 内核状态微圆点。
2. **主工作区列表**：`节点`、`分流规则`、`网络活动`、`日志`。选中态使用 `accent.soft` 圆角胶囊 + 左侧 `3px` 电钴蓝竖条 + `accent.primary` 图标与 Semibold 文字。
3. **底部固定区**：
   - **实时遥测微卡**：显示当前出口节点名、累计 `↓ / ↑` 等宽流量与内核版本（取代旧版臃肿的底部整行状态栏，释放垂直空间！）。
   - **工具行**：`设置`（`Cmd/Ctrl+,` 打开独立设置窗）与 `浅色/深色` 图标切换按钮。

### 1.2 顶部指挥栏（56px，固定于内容区上方）
- **左侧**：当前页面标题（22px Semibold）+ 实时计数胶囊（如 `2 策略组 · 5 节点`）。
- **右侧**：**统一代理与路由指挥组**：
  - **代理开关分段控件**：`已暂停` | `系统代理` | `TUN 代理`（激活态带翠绿脉冲点 + 实体滑块）
  - **路由模式分段控件**：`直连` | `规则` | `全局`

## 2. 五大工作区重设计要点

### 2.1 节点（Nodes）
- **分区一：策略组（优先展示，高频操作一触即达）**
  - 右上角提供 `+ 添加策略组`（主按钮）与 `全部测速`（次按钮）。
  - 卡片网格（Wide 2 列）：每张卡片展示组名、策略徽标（`延迟优选` / `手动选择` / `故障转移`）、**当前出口胶囊**（`SG-02 · 54 ms`）与单组测速图标按钮。
  - 点击展开为紧凑多列节点选择器，支持键盘方向键与鼠标单点即切。
- **分区二：订阅来源与节点**
  - 每个订阅源为独立圆角卡片，头部内嵌 **流量配额进度条**（如 `已用 23.1 GB / 120 GB · 剩余 28 天`）与刷新按钮——彻底告别把“剩余流量”混在节点列表中的粗糙做法。
  - 节点行采用清晰 4 列结构：`[ 地区码 HK ] 节点名称` | `协议胶囊 Hysteria2` | `出口 IP 203.0.113.12` | `信号柱 + 38 ms`。

### 2.2 分流规则（Routing Rules）
- **优先级管道视图**：
  - 顶部提供规则摘要 + `+ 新建规则`（主按钮）+ `+ 新建规则组`（次按钮）。
  - 每个规则组卡片左端带 `01` / `02` 等宽序号 + 六点拖拽把手（Hover 显示 open-hand，键盘聚焦显示 2px 电钴蓝焦点框，支持 `Alt+Up/Down`）。
  - 右侧带皇家紫 **目标策略胶囊**（`→ AI 自动选择`）、启用开关与折叠箭头。
  - 列表最底部固定展示不可删的 **默认兜底卡片**（`FINAL → 默认出口`），清晰闭环匹配顺序。

### 2.3 网络活动（Activity）
- 顶部搜索框 + 实时汇总指标胶囊（`12 条活动 · ↓ 14.2 MB · ↑ 3.1 MB`）+ 刷新按钮。
- 每条连接行突出 **Route Truth Chain**：
  - 主行：域名/主机名（等宽加粗）+ 进程名标签（如 `Cursor` / `Safari`）+ 实时上下行流量（右对齐等宽）。
  - 链路行：`[ 命中: DOMAIN-SUFFIX openai.com ] → [ AI 自动选择 ] → [ 新加坡 SG-02 ]` + 悬停出现 `建规则` 快捷按钮。

### 2.4 日志（Logs）
- 顶部搜索框 + **日志等级过滤胶囊**（`全部`、`ERROR`、`WARN`、`INFO`、`DEBUG`）+ 复制与刷新。
- 等宽日志流，时间戳采用 `text.tertiary`，等级采用 48px 定宽胶囊，正文保持中性 `text.primary` 确保长时阅读不疲劳。

### 2.5 独立原生设置窗 & 编辑器（Utility Windows）
- 沿用独立原生窗口架构（设置默认 `980×760`，编辑器 `720×660`，最小 `480×480`），保留草稿、独立滚动与关闭保护。
- 统一采用 Alabaster/Obsidian 表面层次：固定页头（带 1px 底边）+ 清晰分组表单卡片 + 固定页脚（左侧反馈状态 + 右侧 `取消` 与唯一电钴蓝主提交按钮）。
